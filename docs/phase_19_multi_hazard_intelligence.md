## 1. Executive Summary & Core Objectives

Phase 19 transforms **RISK // INDIA** from an Assam-centric flood prototype into a comprehensive, production-grade **Nationwide Multi-Hazard Disaster Intelligence Platform**.

The platform provides India-wide situational awareness across five core natural hazards:
1. **Flood & River Catchment Inundation**
2. **Seismological Tremors & Earthquakes**
3. **Tropical Cyclones & Coastal Storms**
4. **Extreme Temperatures & Heatwaves**
5. **Rainfall-Triggered Landslides & Slope Instability**

Crucially, nationwide coverage is achieved **without fabricating nationwide machine learning capability**. The architecture strictly isolates and clarifies the **Four Inviolate Pillars of Disaster Intelligence**:
- **LIVE OFFICIAL DISASTER INTELLIGENCE**: Real-time sensor feeds and verified public situation bulletins from official government agencies (USGS, CWC, IMD, GSI, SDMAs).
- **REGIONAL BASELINE RISK**: Deterministic climatological and geological vulnerability indices covering all 28 States and 8 Union Territories based on official NDMA/IMD matrices.
- **EMPIRICALLY VALIDATED ML PREDICTION**: Strictly preserved and geographically bounded to `assam_flood_prototype_v1` with 32 audited ISRO/CWC observations.
- **VERIFIED EMERGENCY RESOURCES**: Audited disaster response shelters, district emergency operation centers (DEOCs), and SDRF battalions.

## 3. Scientific Honesty & ML Scope Non-Negotiables

### 3.1 Preservation of Assam Flood ML Prototype
The trained prototype artifact (`assam_flood_prototype_v1`) remains completely frozen:
- **Model Artifact**: `ml/flood/artifacts/model.joblib` (hash and weights untouched)
- **Preprocessor Artifact**: `ml/flood/artifacts/preprocessor.joblib` (StandardScaler untouched)
- **Metadata**: `ml/flood/artifacts/metadata.json` (13 features, 32 observations)
- **Geographic Bounding**: Strictly active only for validated Assam Brahmaputra/Barak gauge stations.

### 3.2 Non-Assam ML Unavailability is a Feature
When an analysis request is submitted for any non-Assam region (e.g., Bihar, Odisha, Maharashtra), the platform explicitly returns:
```json
{
  "status": "model_scope_limited",
  "message": "AI risk analysis is currently available only for the Assam flood prototype (limited to selected Assam monitoring areas).",
  "data_category": "REGIONAL_BASELINE",
  "why_this_risk": "ML prediction is not currently available for this region. Regional baseline and official disaster intelligence are shown.",
  "methodology": "Regional baseline risk assessment; empirical ML model not validated outside Assam."
}
```
The user interface never presents missing ML models as system bugs or errors. It transparently presents Regional Baseline Risk, Live Official Telemetry, and Verified Relief Resources.

### 3.3 Zero Synthetic Data Guarantee
Under no circumstances are synthetic rainfall measurements, fake gauge stages, imaginary cyclone coordinates, or simulated landslides generated. If upstream telemetry is unavailable, the platform honestly marks the feed as `"UNAVAILABLE"`.

## 4. Modular Hazard Provider Architecture

Providers are decoupled into dedicated, single-responsibility modules in `backend/app/services/hazard_providers/`:

| Hazard Category | Provider Module | Upstream Agency & Feed | Update Mechanism | Circuit Breaker |
|---|---|---|---|---|
| **Earthquake** | `USGSSeismicProvider` | USGS Earthquake Hazards Program GeoJSON API | Automated Real-Time (~10 min cache) | Enabled (threshold=5, cooldown=60s) |
| **Flood** | `CWCFloodProvider` | Central Water Commission (CWC) & ASDMA Bulletins | Daily / Shift Situation Reports | Enabled |
| **Severe Weather** | `IMDWeatherProvider` | IMD National & Regional Meteorological Bulletins | Synoptic Observation Cycles | Enabled |
| **Cyclone** | `IMDCycloneProvider` | IMD Cyclone Warning Division & RSMC New Delhi | Tropical Weather Outlook & Track Bulletins | Enabled |
| **Heatwave** | `IMDHeatwaveProvider` | IMD & NDMA Heat Wave Action Protocols | Seasonal High-Temperature Warnings | Enabled |
| **Landslide** | `GSILandslideProvider` | Geological Survey of India (GSI) LEWS & SDMAs | Rainfall Threshold & Pore-Pressure Advisories | Enabled |

### 4.1 BaseHazardProvider & Circuit Breaker Resilience
Every hazard provider inherits from `BaseHazardProvider`:
- **Circuit Breaker State Machine**:
  - `CLOSED`: Normal operation; requests execute against upstream.
  - `OPEN`: After 5 consecutive failures, calls to the upstream provider are halted for a 60-second cooldown period. Cached events are served with `STALE` freshness.
  - `HALF_OPEN`: After the cooldown, a single probe request is executed. If successful, the breaker transitions back to `CLOSED`.
- **Fault Isolation**: An error or outage in IMD or GSI feeds never prevents USGS earthquakes or CWC flood alerts from being ingested and served.

## 5. Freshness Classification Standards

Every ingested incident and alert includes explicit freshness metadata:
- **`LIVE`**: Observed less than 1 hour ago (`delta_seconds < 3600`).
- **`RECENT`**: Observed between 1 and 24 hours ago (`3600 <= delta_seconds < 86400`).
- **`STALE`**: Observed 24 hours or more ago (`delta_seconds >= 86400`), or served from circuit breaker fallback cache.
- **`UNAVAILABLE`**: Upstream observation timestamp is missing or provider unreachable with no prior cache.

Cached data is **never** disguised as live telemetry.

## 8. REST API Endpoints Catalog

### Disaster Feeds (`/api/disasters`)
- `GET /api/disasters`: Comprehensive disaster list with filters (`state`, `type`, `status`, `freshness`, `live_only`).
- `GET /api/disasters/live`: Verified live and recent disaster events only.
- `GET /api/disasters/by-hazard/{hazard}`: Filtered events for a specific hazard category.
- `GET /api/disasters/by-state/{state}`: Events normalized to an Indian State or UT.
- `GET /api/disasters/flood`: Dedicated CWC flood warnings.
- `GET /api/disasters/earthquake`: Dedicated USGS seismic events.
- `GET /api/disasters/cyclone`: Dedicated IMD/RSMC cyclone alerts.
- `GET /api/disasters/heatwave`: Dedicated IMD/NDMA heatwave warnings.
- `GET /api/disasters/landslide`: Dedicated GSI landslide slope advisories.
- `GET /api/disasters/severe-weather`: Dedicated IMD precipitation alerts.
- `GET /api/disasters/providers`: Audited provider catalog and circuit breaker health.
- `GET /api/disasters/status`: Composite telemetry, hazard counts, and freshness breakdown.
- `GET /api/disasters/{id}`: Single event lookup.

### Risk Intelligence (`/api/risk`)
- `GET /api/risk`: All nationwide regional baseline evaluations (28 States + 8 UTs).
- `GET /api/risk/{location_id}`: Baseline evaluation and "Why This Risk?" rationale for location.
- `POST /api/risk/analyze`: Predictive risk analysis with strict Assam ML scope enforcement.
